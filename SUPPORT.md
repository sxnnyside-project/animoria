# Support

## Getting Help

**GitHub Issues**  
For bugs, unexpected behavior, or general questions, open an [issue](https://github.com/sxnnyside-project/animoria/issues). Use the bug report template for bugs and include enough context to reproduce the problem.

## Before Asking

- Check the [README](README.md) — installation, usage, and architecture are documented there.
- Search existing [issues](https://github.com/sxnnyside-project/animoria/issues) before opening a new one.
