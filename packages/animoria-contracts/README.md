# @animoria/contracts

Shared canonical contracts, domain interfaces, and protocol definitions for the Animoria ecosystem.

## Overview
This package defines the pure contract layer consumed by:
- `@animoria/ui` (Lit Web Components)
- `animoria-vscode`
- `animoria-cli`
- Host bridges and test harnesses

Types can be generated directly from the Rust core engine via `ts-rs` or authored natively in TypeScript.
